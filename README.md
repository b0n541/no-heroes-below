# no-heroes-below
A small kobold crew. A cave full of homemade tricks. An adventuring party that thinks it has seen everything.

## Play the Waking in the Warren prototype

On the `prototype/waking-in-the-warren` branch, open `project.godot` in Godot 4.7 and press **F6** in the prototype scene, or **F5** to run the project's main scene. From a terminal:

```sh
godot --path .
```

If your engine executable has a different name, use that name instead of `godot` (on this machine: `/snap/bin/godot-4`). The prototype keeps all encounter state in memory and uses the supplied art pack.

See the [playtest guide](docs/prototypes/waking-in-the-warren.md) for controls, provisional rules, and verification. The [playable-defense ticket](https://github.com/b0n541/no-heroes-below/issues/3) stays open for the user's verdict.
